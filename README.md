# Ruta Libre Frontend

Ruta Libre Frontend is a responsive web application for a car rental system. It allows users to browse available vehicles, select a car, and simulate the reservation process through an intuitive user interface.

## Technologies

This project was built using:

- React
- TypeScript
- Vite
- Tailwind CSS
- Axios

## Installation

Using npm:

```bash
npm install
```

Or using pnpm:

```bash
pnpm install
```

---

## Run the Development Server

Using npm:

```bash
npm run dev
```

Or using pnpm:

```bash
pnpm dev
```

---

## Build the Project

Using npm:

```bash
npm run build
```

Or using pnpm:

```bash
pnpm build
```

## Features

- Display the list of available vehicles.
- Select a vehicle for reservation.
- Register the customer's name and rental duration.
- Update the vehicle status after a successful reservation.
- Responsive interface built with Tailwind CSS.
- Data retrieved from the backend using Axios.
